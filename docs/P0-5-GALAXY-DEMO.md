# Galaxy S25+ 설치·11월 19일 시연 체크리스트

이 문서는 **실행 절차**입니다. 체크되지 않은 항목은 PASS가 아닙니다.
APK: com.couplereels.mvp, versionCode 5, versionName 0.5-ui-integration, min API 26, target API 35.
기존 com.couplereels.app 재생 검증 앱과 별도로 설치됩니다.

1. 전달 APK의 SHA-256과 `SHA256SUMS`를 비교합니다.
2. `adb install -r CoupleReels-P0-5-debug.apk` 또는 휴대폰의 파일 앱으로 설치합니다.
   기존 앱과 서명이 다르면 설치가 거부됩니다. **기존 앱을 삭제하거나 데이터를 초기화하지 마세요.**
   기존 서명 키를 제공받아 재빌드해야 합니다. 이번 Debug 키는 새 클라우드 환경의 개발용 키입니다.
3. 앱을 열고 “이 기기에만 저장 · 기기 간 동기화 없음” 표시를 확인합니다.
4. 체험 전용 이메일/비밀번호로 가입합니다. 실제 비밀번호는 사용하지 않습니다.
5. 취향 알아보기 1/2에서 관심사 선택 → 다음 → 스타일/선물 선택 → 취향 저장.
6. Instagram의 공개 Reel → 공유 → CoupleReels를 선택합니다. 필요하면 더보기에서 찾습니다.
   Sharesheet 순서는 Android가 결정합니다. 특정 위치 고정은 지원하지 않습니다.
7. text/plain 공유와 image/*+본문 링크 공유 각각 확인합니다. 이미지에 URL이 없으면 직접 입력 안내가 떠야 합니다.
8. 로그인 전 공유 → 로그인 → 같은 링크가 시트에 남는지 확인합니다. 회전/백그라운드/프로세스 복구도 확인합니다.
9. 시트에서 태그 선택 전 저장 비활성, 태그 선택 후 저장, 취소 시 미저장, 같은 URL 재공유 시 중복 병합을 확인합니다.
10. 보관함에서 링크, 관심 토글, 삭제를 확인합니다. 공유한 원본은 상대 보관함에 나타나면 안 됩니다.
11. 우리 → 초대 코드 만들기 → 코드 복사. 계정 설정 → 로그아웃 → 두 번째 체험 계정 가입 → 우리 → 코드 입력.
    로컬 체험은 **같은 기기**에서 두 계정을 번갈아 사용합니다. 두 폰 동기화 시연으로 소개하지 않습니다.
12. 양쪽 계정에서 태그를 저장하고 상대 계정 발견 피드를 확인합니다. 후보 태그 편집은 직접 영상을 확인한 경우에만 합니다.
13. 실제 재생은 공개 Reel을 직접 터치하고 움직임과 소리를 관찰해야 합니다.
    로그인 요구/HTTP 오류/임베드 실패는 실패로 기록하고 Instagram에서 열기 또는 링크 복사를 시연합니다.
14. 연결 해제 확인 대화상자 → 해제 → 상대 정보 접근 종료, 개인 취향과 보관함 유지.
15. 글자 크기 확대, 작은 화면, 키보드, 뒤로가기, 세로 스와이프, 상태/내비게이션 바 가림 여부를 확인합니다.

## 발표에서 구분해서 말할 것

- 구현: 4탭 UI, 취향 2단계, 공유 URL 검증/정규화, 태그 저장, 보관함, 로컬 계정 연결, 기존 추천 엔진.
- 자동 검사로 확인: QA 문서의 실제 실행 결과만 인용합니다.
- 현장에서 확인해야 할 것: Galaxy Sharesheet 노출/순서, 실제 Instagram 재생, 폰별 WebView 동작.
- 미완료: 운영 Firebase 연결·두 폰 동기화 검증, 완전 비공개 서버 추천, 합법적인 대규모 후보 공급.
- 로컬 체험 화면을 실서비스 동기화나 Instagram 자체 알고리즘 변경으로 소개하지 않습니다.
