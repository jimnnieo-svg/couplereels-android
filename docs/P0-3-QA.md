## 자동 테스트

기존29개를 삭제하지 않고 유지했습니다. 새로운 테스트15개를 추가해 총44개, 실패0/오류0/skip0입니다.

- 기존29개: URL6, 추천/Fake16, 시작1, 오류안내6.
- 교차 추천 통합9개: 관찰 피드 갱신, 9개 후보, 해제, 계정별 catalog, 잘못된공유, 동시연결경합,
  두계정 복원, 새커플 격리, 저장/재공유 관심유지.
- 공유/내부이동4개: ACTION_SEND, 프로필/MIME거부, 명시적 내부 Activity, 위험 URL거부.
- 실제 Compose 계정·연결·공유흐름1개 (Robolectric).
- 원본 P0 Probe 수동기록/내보내기1개 (Robolectric, 결과는 '미확인').

테스트에 부여한 silver/date 후보 태그는 테스트 픽스처입니다. 해당 실제 영상의 내용 분석 결과가 아닙니다.

## 이번 수정

PartnerFeed.build/observe를 UI와 통합 테스트가 함께 사용합니다.
인증·커플·파트너 취향·계정별 후보분류 상태를 조합하고 연결 해제 시 빈 피드를 반환합니다.
태그가 없으면 기다림 안내, 후보가 줄면 실제 개수를 표시합니다. 미분류 후보 수와 최대10개 제한도 표시합니다.
계정 전환 시 이전 계정 후보분류가 로드되는 동안 피드를 노출하지 않습니다.
ACTION_SEND 반복 수신 시 같은 링크도 다시 입력 화면을 엽니다. 로그인 전 입력은 유지합니다.
singleTask 진입과 명시적 내부 재생 Intent를 사용합니다. 불필요한 중복 진입 화면을 줄였습니다.
일반 저장/원본 재공유는 기존 관심을 제거하지 않습니다. 실제 Firebase 구현에도 같은 동작을 트랜잭션으로 반영했습니다.
