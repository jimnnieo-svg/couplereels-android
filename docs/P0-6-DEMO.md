# 11월 19일 발표 준비 — 1~2분

실행 결과와 실제 화면은 P0-6-QA.md의 상태가 기준입니다. BLOCKED/FAIL 기능을 완성 기능으로 소개하지 않습니다.

## 시연 전 사용자 확인

- Galaxy S25+에서 APK 해시/서명 확인 후 **업데이트 설치**합니다. 서명 불일치 시 기존 앱/데이터를 삭제하지 않습니다.
- 로컬 체험 문구를 확인합니다. 서로 다른 폰의 서버 동기화로 소개하지 않습니다.
- 두 개의 체험 전용 계정을 미리 준비합니다. 실제 비밀번호를 사용하지 않습니다.
- Instagram 공유 목록 노출, text/plain 및 이미지+링크, URL 없는 이미지 안내를 확인합니다.
- 로그인 전 공유, 취소, 회전/재시작 후 URL 유지, 중복 링크 저장을 확인합니다.
- 글자 크기 확대/키보드/시스템 바/세로 스와이프/터치 영역을 점검합니다.
- 실제 영상은 움직임·소리를 직접 관찰해야 합니다. HTTP 200/페이지 로드/자동 테스트는 재생 성공이 아닙니다.
- 운영 Firebase 연결이나 규칙 적용은 별도 승인·검토가 필요합니다.

## 90~110초 권장 순서

1. **0~15초**: 버건디×골드 앱과 4탭 소개. “기기 내부 로컬 체험이며 검증 범위를 구분합니다.”
2. **15~30초**: 취향 1/2 관심사 → 2/2 스타일·선물 → 내 취향. 미리 만든 계정으로 입력 시간을 줄입니다.
3. **30~50초**: 공개 Reel 링크를 Android 공유로 전달 → 태그 → 저장 → 보관함 확인.
   Instagram 앱에서 사전 확인하지 못했다면 “Android 공유 전달 경로 시연”이라고 말합니다.
4. **50~75초**: 초대 코드와 두 번째 체험 계정 연결 → 상대 추천 피드 → 보관함 저장.
   동일 기기의 두 계정 시뮬레이션이며 실제 두 폰 동기화가 아닙니다.
5. **75~90초**: 원본 링크·태그·해시를 직접 전달하지 않는 변경과 연결 해제 후 접근 종료를 설명합니다.
6. **90~110초**: 실제 재생이 검증됐을 때만 재생. 제한되면 오류 안내/Instagram 열기/복사를 보여줍니다.
   제한된 후보+수동 태그 기반임을 명시하고, 기념일 일정·선물 상품 추천은 구현 범위를 구분합니다.

## 미완료 기능과 대체 설명

- 기념일 **태그**와 선물 취향 선택은 존재하지만 날짜 관리·알림·선물 상품 DB/상품 추천 서비스는 없습니다.
- 추천 후보는 기존 10개 공개 URL 범위이며 현재 공개/재생 여부와 콘텐츠 유사도를 보장하지 않습니다.
- 실제 실행 캡처만 발표 화면으로 사용합니다. 시스템 대화상자로 가린 캡처나 미확보 화면을 정상 앱 화면으로 대체하지 않습니다.
- 모바일 완주 검사가 통과하지 않았다면 라이브 전체 흐름을 확정하지 말고, 확인된 화면/테스트 결과와 미완료 원인을 발표합니다.
