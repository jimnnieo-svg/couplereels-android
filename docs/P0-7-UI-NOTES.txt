Photos and truthfulness
Only clean photographic rectangles are extracted from supplied mockups; see P0-7-assets.json.
No full-screen screenshot, baked text, button, checkbox or navigation image is used as a screen.
All screen chrome, typography, decorations, cards and controls are native Compose elements.
Demo photos have no invented Instagram URLs or video playback. The center control is an information
button rather than a play triangle, because these assets contain no playable video.
Actual saved URLs use explicitly labelled tag illustrations, not claimed original thumbnails.
Original URLs remain accessible through the existing official embed/external/copy controls.
No scraping, media downloading or external service bypass is implemented.

Data compatibility
Package remains com.couplereels.mvp; versionCode 7, versionName 0.7-ui; same debug signing configuration.
DemoStore.NAME, the P0-6 snapshot schema, Domain models, and Firebase repository are unchanged.
Taste/gift editing uses the existing tag vocabulary and P0-6 persistence operations.
The additional couplereels-demo-content-p07-v1 preferences store only editorial demo IDs in
liked/bookmarked/hidden sets. They never create account identities or counterfeit saved Reel URLs.
They are guest-only UI interactions; the account repository does not receive these demo reactions.
Existing user data and launch icon must not be deleted to resolve an installation conflict.

Testing
Domain/storage tests remain testDebugUnitTest. Six Compose UI cases are androidTest tests run on
an explicitly addressed disposable emulator, using AndroidJUnitRunner. They clear test fixtures.
Do not run connectedDebugAndroidTest against all connected devices: it could affect the user's phone.
Use adb -s <dedicated emulator> install and am instrument with com.couplereels.mvp.test runner.
Robolectric Compose was unsuitable here: PAUSED previously stalled at ActivityScenario.close;
INSTRUMENTATION_TEST exposed Espresso's main-thread conflict. The tests were moved, not disabled.
Reference: https://robolectric.org/javadoc/4.13/org/robolectric/annotation/LooperMode.Mode.html
