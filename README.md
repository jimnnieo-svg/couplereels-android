# CoupleReels 소개 웹사이트

이지민 · 컴퓨터소프트웨어학과 · 개인 바이브코딩 프로젝트.

Android 저장소와 분리된 React + TypeScript + Vite 정적 웹사이트입니다.
P0-8 기준 커밋: `4e465863ff08556467dc090af72d28d9980a1d4f`.
Android 코드, APK, 사용자 데이터는 이 웹 프로젝트가 수정하지 않습니다.

## 개발

```sh
npm ci
npm run dev
npm run build
npm test
```

- `src/main.tsx`: 페이지 구성, 실제 앱 화면 갤러리, 다운로드 링크, DIRECT/SIMILAR 설명.
- `src/Story.tsx`: 사용자 제공 기획 배경, 네 단계 스토리, 개발자 메시지.
- `src/light-theme.css`: 최종 아이보리·소프트 핑크·로즈 골드 테마, 반응형 조정.
- `src/style.css`: 기본 레이아웃, 구성요소, 접근성/움직임 축소.
- `public/screens`: 실제 앱 화면의 공개용 사본 8장. 원본과 식별정보는 포함하지 않음.
- `public/site-qr.png`: 공개 사이트 QR.
- `public/og.png`: 소셜 미리보기.
- `scripts/verify.mjs`: 빌드 결과, 링크, 배포 설정 검사.
- `.openai/hosting.json`: Sites 정적 배포 설정. 비밀정보 없음.

## 이미지 출처와 표시 기준

사용자가 제공한 실제 P0-8 스크린샷 ZIP의 발견·취향·보관함·우리·Instagram 공유 화면 5장을 사용했습니다.
카테고리·개별 공유 설정·미리보기는 앞선 Galaxy 실기기 검증에서 확보한 실제 앱 캡처입니다.
공개용 사본에는 원본 URL, 콘텐츠 식별자, 외부 영상/계정, 개인 공유 대상 일부를 불투명 영역으로 가렸습니다.
색상이나 앱 컨트롤은 재디자인하지 않았습니다. 원본 ZIP과 개인 데이터 백업은 웹 소스에 포함하지 않았습니다.
꽃·카페 벡터 및 흐름/공유 모드 애니메이션은 설명용 시뮬레이션으로 표시합니다.

## 실제 구현과 한계

P0-8은 로컬 두 프로필, 즉시 저장, 규칙 분류, DIRECT 공개/SIMILAR 원본 비공개를 구현했습니다.
새 유사 릴스 검색, AI 영상 분석, 실제 커플 계정 동기화는 미구현입니다.
공식 임베드는 표시를 시도하며 모든 영상 재생을 보장하지 않습니다.
77개 테스트는 Android P0-8의 기존 검증 결과이며 웹 자동 테스트 수가 아닙니다.

## 다운로드

첫 화면·상단 메뉴·마지막 다운로드 섹션은 사용자가 지정한 Google Drive 파일 페이지를 새 탭으로 엽니다.
2026-11-19 비로그인 브라우저에서 다운로드 완료. 로컬 원본과 다운로드 파일 SHA-256 일치:
`6f25eedbeb2ea2ee595bfbe38eb978e019ea8dd8de63936395ff3b0bcdaa005c`.
파일은 재서명·변환·재배포하지 않았습니다. Google Drive에서 실행 파일 검사 불가 안내가 나올 수 있습니다.

## 게시와 Git

Android 저장소의 비공개 설정을 보존하기 위해 소개 웹은 별도 Sites 호스팅에 공개합니다.
소스는 별도 웹 브랜치에도 보관하며 Android 기본 브랜치에 병합하지 않습니다.
GitHub Android 저장소 링크는 권한 있는 사용자만 열 수 있다고 페이지에 표시합니다.
배포 이후 Drive 권한 변경이나 외부 서비스 제한은 다운로드에 영향을 줄 수 있습니다.

## 검증

TypeScript 및 프로덕션 빌드, 8개 정적 검사, 실제 브라우저 메뉴/스토리/갤러리/모달/공유 방식 전환 확인.
PC 및 모바일 뷰포트 검증. 자동화된 전체 WCAG 적합성 인증이나 실제 모든 모바일 브라우저 테스트는 수행하지 않았습니다.
Google Fonts로 Noto Sans KR/Serif KR을 로드하며 네트워크 제한 시 시스템 글꼴로 대체합니다.

## PPT 사진 스토리 추가

최신 요청에 따라 PC 웹 기준으로 추가했습니다. 메인/밝은 디자인/APK 링크를 유지합니다.
- `src/PhotoStory.tsx`, `src/photo-story.css`: 외부 사례 3장, 흐림 릴스 3장, 기획 시안 2장과 현재 앱 비교.
- `public/image-sources.json`: 첨부 ZIP에서 사용한 13장(위 8장 + 실제 앱 5장)의 원본 파일명과 공개 사본 목록.
- `scripts/prepare-story-assets.py`: 원본 비율을 유지하며 최적화하고 Instagram 이미지 전체를 픽셀 수준에서 흐림 처리합니다. 원본 게시물 파일을 공개하지 않습니다.
- 사진 확대는 키보드 Escape/닫기 버튼으로 닫을 수 있는 native dialog입니다.
- 이미 만들어진 반응형 스타일은 보존하지만 최종 수정은 PC 웹에서 검증합니다. 별도 모바일 앱을 제작하지 않습니다.
